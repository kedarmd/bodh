# Bodh

Linux-native PR review workspace. The build specification is [issue #1](https://github.com/kedarmd/bodh/issues/1); the current runnable code is a [disposable native renderer spike](spikes/native-sequence/README.md).

Run `./scripts/validate` for core checks or `./scripts/validate desktop` for the native build and tests. See [TESTING.md](TESTING.md) for prerequisites, CI coverage and GUI evaluation.
