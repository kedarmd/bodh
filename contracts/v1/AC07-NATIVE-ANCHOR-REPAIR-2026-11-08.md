## Fixes made during the trial

The trial exposed two native view defects. Anchor recovery returned only the first earlier preparation with local drafts, hiding older changed anchors when another prior preparation had work. It now aggregates all earlier preparations and computes the candidate diff index once; `tests/manual_drafts.rs::anchor_repair_preview_collects_drafts_from_every_earlier_preparation` covers the aggregation. Resume also started the scan before restoring a saved file selection, whose cancellation epoch could discard the scan response and leave the panel showing “Checking older local drafts” indefinitely. Resume now starts the scan after restoring that selection.

`CARGO_BUILD_JOBS=2 ./scripts/validate desktop` passed after both fixes. The complete output is [here](VALIDATE-AC07-ALL-ANCHOR-PREVIEWS-2026-11-08.log), and the focused multi-preparation regression output is [here](AC07-ALL-PREPARATIONS-TEST.log).

- **Ambiguous-anchor manual recovery:** The repeated `.items_center()` anchor was marked ambiguous with no automatic destination. After selecting the exact Head diff line 1, explicit attachment created a candidate copy at line 1, while the original stayed at line 7355. See [ambiguous preview](../../spikes/native-sequence/evidence/issue-37-ac07-ambiguous-anchor-2026-11-08.png) and [confirmed manual attachment](../../spikes/native-sequence/evidence/issue-37-ac07-ambiguous-reattach-confirmed-2026-11-08.png). An initial interaction retained the broad default 1–80 source selection; that copy was discarded and is excluded from the successful result. The retry selected the exact diff row before attaching.
- **Discarded-copy recovery:** Discarding an attached copy previously left its idempotency record behind, so the preview could claim “Already copied” after the target draft was gone. `DraftStore::discard` and `discard_replacement` now remove that target link. The relocation service regression discards a copy, confirms the proposal returns, then reattaches a fresh copy while preserving the source draft.
